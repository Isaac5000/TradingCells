## Cambios deliberadamente aplazados

No se dividieron `FarmerCropStackAdapter`, Trader, Autotrader ni las categorias
REI. El plan exige primero equivalencia manual, multijugador y plantillas de
rendimiento comparables; hacer esos refactors ahora aumentaria el riesgo sin una
medicion que los justifique.

Tampoco se conservaron nuevas optimizaciones de produccion. Las dos rutas ya
aceptadas se revalidaron y la unica hipotesis repetida del Autotrader no alcanzo
su umbral.
