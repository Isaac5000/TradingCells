# Infusiones de huevos retiradas

86 recetas originales, fuera de `src/main/resources` y del JAR. Recuperacion
manual solamente: copiarlas a un datapack o actualizar explicitamente el
contrato si vuelven al proyecto. No se cargan ni se muestran en REI.

Wither y Ender Dragon se eliminaron sin copia por peticion expresa.
La ruta activa es `creature_generator`: nucleo clasificado + base del mismo
tier, con 1000/4000/16000/64000 XP y lista negra configurable en servidor.
